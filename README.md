# 🌐 Мой Личный Сайт-Портфолио

Современный, адаптивный сайт-портфолио, созданный для демонстрации моих проектов, ключевых навыков и опыта работы в сфере веб-разработки.

## Важно.
Рендер устроен так что если сайт не пингуется 15 минут то при следующем открытии сайта происходит его сборка это занимает примерно 10 секунд(просьба подождать)

## 🚀 Стек технологий

В данном проекте используются следующие инструменты и библиотеки:
* **Frontend:** HTML, CSS
* **Backend:** Golang
* **Database** PostgreSQL
* **Среда** Docker, Docker-compose

* **Как развернуто:** Render - Backend && Neon - Database

## ✨ Основные возможности

* **Адаптивный дизайн:** Сайт полностью оптимизирован под мобильные устройства, планшеты и десктопы.
* **Интерактивное портфолио:** Удобный просмотр кейсов с фильтрацией по категориям (веб-сайты, приложения, дизайн).
* **Форма обратной связи:** Рабочая форма для отправки сообщений напрямую на мою почту.

## 📂 Структура проекта

```text
├── public/          # Статические ресурсы (иконки, шрифты)
├── src/
│   ├── assets/      # Изображения и медиафайлы
│   ├── components/  # Переиспользуемые UI-компоненты (Header, Footer, Card)
│   ├── sections/    # Основные блоки сайта (Hero, About, Projects, Contacts)
│   ├── styles/      # Глобальные стили и конфигурации темы
│   └── main.js      # Точка входа в приложение
├── index.html       # Главный HTML-документ
└── package.json     # Конфигурация проекта и зависимости
```
